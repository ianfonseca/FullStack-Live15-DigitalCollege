h1>IF - ELSE - ELSEIF

O if é uma estrutura condicional que permite executar um bloco de código se uma condição for verdadeira. O else é usado para executar um bloco de código se a condição do if for falsa. O elseif (ou else if) permite verificar múltiplas condições.

Exemplo:

let idade = 20;
if (idade < 18) {
console.log("Menor de idade");
} else if (idade >= 18 && idade < 65) {
console.log("Adulto");
} else {
console.log("Idoso");
}
